# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep the discussion on the work. Harassment, insults and personal attacks are
not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainers through this repository's
**Security → Report a vulnerability** form, marking it as a conduct report. Every report is reviewed and kept
confidential, and the maintainers may remove content or block participants who break this code.
